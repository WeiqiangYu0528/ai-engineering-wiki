## Concepts

- [[active-prompt]] — Active-Prompt (Diao et al., 2023) is a data-driven few-shot prompting technique that replaces a fixed, human-chosen chain-of-thought exemplar set with an uncertainty-based selection. (aka: Active Prompting, Active Prompt) · `draft`
- [[automatic-prompt-engineer]] — Automatic Prompt Engineer (APE) (Zhou et al., 2022) is a black-box framework that uses a large language model itself to generate and search over natural-language instructions. (aka: Automatic Prompt Engineering) · `draft`
- [[context-caching]] — Context Caching is the managed prefix/KV-cache reuse for large static contexts so repeated queries over the same corpus avoid resending and recomputing the full prompt. (aka: Prompt Caching, Cached Content) · `draft`
- [[context-engineering]] — Context Engineering is the evolution of Prompt Engineering into the discipline of curating and maintaining the optimal token set during LLM inference — not just writing system prompts, but continuously selecting what… (aka: Context Design, Prompt System Engineering) · `draft`

- [[infini-attention]] — Infini-attention (Google, arXiv 2404.07143) integrates a compressive memory into vanilla dot-product attention so a Transformer can process effectively infinite-length inputs with bounded memory and compute. (aka: Infinite Context Transformer, Compressive Memory Attention) · `draft`
- [[inference]] — LLM Inference refers to the execution phase where a trained language model processes prompt tokens (prefill phase) and generates new tokens sequentially (decoding phase). (aka: Model Serving, Autoregressive Decoding) · `draft`

- [[meta-prompting]] — Meta Prompting (Zhang et al., 2024) is a structure-oriented, syntax-focused technique that teaches an LLM the form of a solution rather than its content. (aka: Meta-Prompting, Structural Prompting) · `draft`
- [[mixture-of-experts]] — Mixture of Experts (MoE) replaces a dense feed-forward network (FFN) in a Transformer block with many parallel FFNs ("experts") plus a router that selects a small subset per token ($k$ out of $E$). (aka: MoE, Sparse MoE) · `draft`

- [[program-aided-language-models]] — Program-Aided Language Models (PAL) (Gao et al., 2022) prompts an LLM to generate programs — not free-form text — as intermediate reasoning steps, then offloads execution to a programmatic runtime (e.g., Python… (aka: Program-Aided Reasoning, Code-Aided Prompting) · `draft`

- [[reasoning-llms]] — Reasoning LLMs (Large Reasoning Models, LRMs) are models explicitly trained to perform native chain-of-thought — generating hidden deliberation traces before answering — enabling inference-time compute scaling. (aka: Large Reasoning Models, LRMs) · `draft`
