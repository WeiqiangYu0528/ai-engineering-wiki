# Polo Club of Data Science

## Overview
The **Polo Club of Data Science** is a premier research laboratory at the **Georgia Institute of Technology**, directed by Professor Duen Horng (Polo) Chau. The lab specializes in human-centered AI, visual analytics, scalable data science, and interactive AI interpretability systems designed to demystify complex deep learning models for researchers, students, and practitioners.

## Key Facts
- **Transformer Explainer (2024):** Created [[source-transformer-explainer]], an interactive browser-based visualizer running a live GPT-2 model via ONNX Runtime Web to explain tokenization, self-attention projection matrices, and sampling dynamics. Published at IEEE VIS 2024.
- **Suite of Deep Learning Explainers:** Pioneered landmark interactive web tools for machine learning education, including:
  - *CNN Explainer:* Interactive visualizer for convolutional neural networks.
  - *GAN Lab:* Interactive generative adversarial network sandbox in collaboration with Google Brain.
  - *Diffusion Explainer:* Interactive visual exploration of Stable Diffusion and latent diffusion models.
- **Impact:** Tools developed by the lab have been used by over 3 million learners and incorporated into computer science curricula globally.

## Significance in AI Engineering
- Bridges the gap between abstract mathematical equations (tensor projections, attention dot products, temperature sampling) and intuitive mental models through interactive visual execution.
